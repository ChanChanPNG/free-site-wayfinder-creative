# Wayfinder Creative — Local Business Sponsorship

Complete buildless static site for https://freesite.wayfindercreative.net/.

Open index.html directly, or serve this folder with any static web server. No installation, build, external fonts, or JavaScript dependencies are required. Upload this directory's contents to the static host's public root. DNS and hosting for the custom domain are not configured by these files.

## Add the application form

In index.html, replace the contents of #ghl-form-slot with the provided GoHighLevel embed. Remove the placeholder class and placeholder messaging when integrating. Keep the accessible region label. Confirm the embed uses responsive width, has a descriptive iframe title if relevant, and supports keyboard interaction. The website goal list has been removed from the page as requested. Configure goal options in the actual form when provided. The live GoHighLevel form collects submissions through LeadConnector.

## Assets and editing

- assets/elevated-window-cleaning.png is the original screenshot recovered from the referenced chat attachment.
- styles.css contains forest/orange branding, responsive layouts, focus states, and reduced-motion support.
- script.js adds progressive scroll reveals; content works without JavaScript.
- Both the screenshot and ElevatedWindowCleanings.com label link to the approved Vercel project URL.
- The SVG social card is an editable source. Some social platforms require a PNG/JPEG; replace the og:image with a raster version before a social campaign.

No application deadline or geographic boundary beyond “local community” is specified. The site is delivered locally and has not been published.
